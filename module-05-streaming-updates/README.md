# Module 05: Streaming Updates

Receive real-time session updates (messages, thoughts, tool calls, plans) during prompt processing.

## Documentation

Full tutorial: https://lab.pollack.ai/docs/acp-java-sdk/tutorial/05-streaming-updates

## Running

Requires the Grok CLI on your `PATH`, signed in once with `grok login`.
The module launches it as `grok agent stdio`; no API key is needed.

```bash
./mvnw exec:java -pl module-05-streaming-updates
```
