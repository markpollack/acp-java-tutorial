# Module 06: Update Types

All seven SessionUpdate types and how to handle them.

## Documentation

Full tutorial: https://lab.pollack.ai/docs/acp-java-sdk/tutorial/06-update-types

## Running

Requires the Grok CLI on your `PATH`, signed in once with `grok login`.
The module launches it as `grok agent stdio`; no API key is needed.

```bash
./mvnw exec:java -pl module-06-update-types
```
