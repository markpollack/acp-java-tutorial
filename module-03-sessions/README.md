# Module 03: Sessions

Session lifecycle — create, use, and manage sessions.

## Documentation

Full tutorial: https://lab.pollack.ai/docs/acp-java-sdk/tutorial/03-sessions

## Running

Requires the Grok CLI on your `PATH`, signed in once with `grok login`.
The module launches it as `grok agent stdio`; no API key is needed.

```bash
./mvnw exec:java -pl module-03-sessions
```
