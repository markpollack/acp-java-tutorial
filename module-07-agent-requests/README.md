# Module 07: Agent Requests (Client Side)

Handle file read/write requests from agents.

## Documentation

Full tutorial: https://lab.pollack.ai/docs/acp-java-sdk/tutorial/07-agent-requests

## Running

Requires the Grok CLI on your `PATH`, signed in once with `grok login`.
The module launches it as `grok agent --always-approve stdio`; no API key is needed.

```bash
./mvnw exec:java -pl module-07-agent-requests
```
